一、显示器不亮

  1. 优先排查显示器后方 DP 线 和 电源线 是否插紧。
    ⚠️ 目前几乎所有门店 90% 以上使用机械臂，机械臂来回挪移会导致 DP 线和电源线接触不良。
  2. 若无效，查看显示器是否通电。
  3. 若显示器仍没电，在保证插排通电的情况下，更换一根电源线，重新插上。
  4. 若更换新电源线后仍不供电，基本可断定 显示器电源插口有问题，需要更换显示器去售后。
  5. 若显示器通电但不亮，优先打开机箱，查看主板 4 个指示灯，确认主板运行是否正常。
  6. 若显示 黄灯，且显示器显示无信号，代表内存有问题：
    • 拔下内存条，用橡皮擦擦拭，去除静电。
    • 更换一个内存插槽重新插上，反复试验。
    • 若仍不行，找一根备用的好内存条，排查是否是原内存条损坏。
  7. 若打开机箱后主板指示灯均正常，但显示器仍无信号、连不上主机信号，则找一根新的 DP 线更换插上。

二、主板指示灯说明

指示灯含义
红灯长亮CPU 有问题
黄灯长亮内存有问题
绿灯长亮显卡接触不良，或显卡有问题
白灯闪烁主板所有硬件均正常，已正常开机

三、耳机不响

  1. 优先查看耳机上 声卡位置的按钮：若有带小喇叭且上面有个叉的图标，代表静音，按一下，排查是否是硬件按钮被顾客误触。
  2. 若硬件排查后仍不行，查看桌面右下角小喇叭 → 声音，检查音量是否正常。
  3. 点开小喇叭 → 声音 → 扬声器，查看级别，确认声音是否正常运转。
  4. 若仍没有声音，给顾客更换一个耳机。
  5. 若是飓风这类分体式耳机，没有声音时，优先拔掉声卡，重新插，排查声卡是否插紧。
  6. 两款耳机都需提前排查耳机插在主机那一侧的 USB 插头是否松动、接触不良。

四、麦克风没声音

  1. 非飓风类耳机：点开声音 → 播放 → 录制，里面有一个 Microphone（麦克风）小图标，查看是否为打开状态。
  2. 若不行，查看耳机上的操作键、操作按钮，排查是否是硬件物理静音按钮被顾客打开了。
  3. 飓风类耳机：优先查看声卡和飓风自带耳麦的接口（飓风耳机是分体式），排查是否接触不良。
  4. 排查接触不良后仍不行，把飓风耳机的麦拔掉，去楼下换一个新的耳麦。
  5. 若换新耳麦后仍不可以，给顾客换一个新耳机，把旧的放好，等待售后人员检测、售后。

五、无线鼠标不动

（一）罗技类鼠标

  1. 把鼠标翻过来，查看底部开关是否打开。
  2. 打开鼠标后盖，查看鼠标标号与机器号、接收器号是否对得上。
  3. 排查机箱里面是否插了接收器。
  4. 如果接收器和鼠标的标号一致还不管用，打开罗技驱动查看接收器和驱动是否连接上：
    • 如果显示为连接，把接收器换一个 USB 口插，排查是接收器坏了还是主板 USB 接口坏了：接收器坏了就换个新的接收器重新配对；主板插口坏了联系领班换掉主板，交给售后人员售后。
    • 如果接收器和驱动可以连接上，那就给鼠标重新配对（配对方法看下方视频）。
  5. 若配对后仍不行，说明接收器坏了或硬件部件有问题，需找领班：
    • 领班能解决的，让领班解决。
    • 领班解决不了的，让领班去找售后工作人员。
▶ 视频罗技鼠标配对方法

（二）非罗技鼠标（如腾龙、达尔优标配带充电底座）

  1. 同样先排查鼠标开关是否打开。
  2. 若已打开仍不行，找领班。
  3. 领班解决不了，让领班去找售后维修人员。

六、外设租赁柜键盘

若遇到个别按键按不动，或长按时出现停顿：

  1. 优先找到此外设的驱动。
  2. 找到设置，拉到最下方，有“重置”。
  3. 点击“重置所有设置”，即恢复出厂设置。
  4. 重置后再确认是否好用。

七、通用原则

解决不了的问题，优先给顾客换一个能用的外设，不要让顾客一直等着维修。一切以顾客玩得舒服、不耽误顾客打游戏为基础。
